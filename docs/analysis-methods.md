# 分析手法の出どころ

スキルの[調査手順](../skills/skill-anatomy/references/research.md#分析の手法)が使う4つの手法と、参照した資料、公開ソースの分析に当てはめるときの限界をまとめる。スキル本体には手法の使い方だけを置き、出典と限界はここに残す。

| 手法 | 参照資料 | 取り入れる点・適用の限界 |
|---|---|---|
| ケーススタディ | [Yin『Case Study Research and Applications』出版社公開抜粋](https://uk.sagepub.com/sites/default/files/upm-assets/87275_book_item_87275.pdf) | 事例と範囲を決め、複数の資料を照合する。公開ファイル・差分・議論を読むために使う。 |
| QOC（問い・選択肢・判断基準） | [MacLeanほか、QOC、1991](https://www.tandfonline.com/doi/abs/10.1080/07370024.1991.9667168) | 問い・選択肢・判断基準を分ける。作者が実際に検討した順序を示す記録とは限らない。 |
| パターン抽出 | [Alexanderほか『A Pattern Language』出版社の説明](https://www.oup.com.au/books/general-interest/art-technology/9780195019193) | 問題と解決方法を具体例で表す。「課題・動作・適用条件」はスキル分析向けの整理で、建築の方法をそのまま移さず、1事例の工夫を広く実証済みとしない。 |
| 類推 | [Gentner、Structure-Mapping、1983](https://groups.psych.northwestern.edu/gentner/papers/Gentner83.2b.pdf) | 名前や見た目でなく、役割・動作の関係を対応付ける。異なる条件と変える点も示す。 |

手法の選定経緯は [Issue #68](https://github.com/yamazaki-yuki-23/skill-anatomy/issues/68) にある。
